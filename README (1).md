## Core command reference

| Command | Purpose |
|---|---|
| `pwd` | Show current directory |
| `whoami` | Show current user |
| `hostname` | Show machine name |
| `ls -la` | List files, including hidden entries |
| `cd /path` | Change directory |
| `cat file` / `less file` | Read a file |
| `head` / `tail` | Inspect file beginning/end |
| `grep` | Search text |
| `find` | Search filesystem paths |
| `stat` | Inspect file metadata |
| `chmod` / `chown` | Change permissions / ownership |
| `ps` / `top` | Inspect processes |
| `crontab -l` | List current user's cron jobs |
| `systemctl status` | Inspect a service on systemd systems |
| `journalctl` | Query the systemd journal |

Commands and paths vary by distribution. Use elevated privileges only when necessary and permitted.
