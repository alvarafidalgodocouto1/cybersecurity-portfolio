# Cyber Security 101 — Search Skills

## Purpose

Security professionals regularly research unfamiliar domains, investigate indicators, read vendor documentation, and validate claims. Search skills help find relevant information while reducing the risk of relying on outdated or misleading sources.

## A structured search approach

1. Define the question and the information needed.
2. Search using specific technical terms, product names, error messages, or identifiers.
3. Prefer primary sources such as vendor documentation, standards, official advisories, and original research.
4. Check publication dates and whether the information applies to the software version or environment.
5. Compare independent sources for important claims.
6. Record links and the date accessed where appropriate.
7. Treat retrieved content as data to evaluate, not as instructions to follow blindly.

## Search operators

Common search engines support operators such as:
- Quoted phrases for exact wording: `"exact error message"`
- Domain restriction: `site:vendor.example security advisory`
- File type filters: `filetype:pdf incident response`
- Excluding a term: `security logs -marketing`

Operator support can vary by search engine.

## Security research cautions

- Do not upload confidential logs or personal data to public services without approval.
- Validate indicators with context; IP addresses and domains can change ownership or purpose.
- Avoid downloading or executing unknown files simply because a search result recommends them.
- Preserve source URLs and timestamps when preparing an investigation report.

## Key takeaways

- Make searches specific and iterative.
- Prefer authoritative, current sources.
- Corroborate high-impact claims.
- Document the source and avoid exposing sensitive data.
