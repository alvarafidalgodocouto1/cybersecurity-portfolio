# Pre Security — Introduction to Cyber Security

## Module overview

This module introduces the cybersecurity landscape, the difference between offensive and defensive security, and common career paths. It provides vocabulary for understanding how organisations identify weaknesses and protect systems.

## 1. Offensive security

Offensive security tests systems from an adversarial perspective to discover weaknesses before malicious actors exploit them. Work must be authorised, scoped, and documented.

Typical activities include reconnaissance, vulnerability assessment, penetration testing, controlled exploitation, and communicating remediation advice.

## 2. Defensive security

Defensive security protects systems and information by preventing, detecting, investigating, and responding to threats. Activities include hardening systems, monitoring logs, reviewing alerts, threat hunting, incident response, and recovery.

## 3. Blue team, red team, and purple team

- **Red team:** Simulates adversary behaviour within an authorised scope.
- **Blue team:** Detects, investigates, and responds to threats.
- **Purple team:** Improves collaboration and feedback between offensive and defensive teams.

These labels describe functions, not necessarily separate departments in every organisation.

## 4. Security operations

A SOC analyst may triage alerts, validate events, collect supporting telemetry, determine severity, escalate incidents, and document findings. An alert is a starting point for investigation, not proof by itself that a compromise occurred.

A useful workflow is: validate → gather context → correlate evidence → assess impact → escalate/respond → document.

## 5. Careers in cyber

Cybersecurity includes security operations, incident response, digital forensics, penetration testing, security engineering, application security, governance/risk/compliance, and cloud security. Each role requires a different balance of technical depth, communication, and process knowledge.

## Skills and vocabulary

- Asset, threat, vulnerability, exploit, risk
- Detection, triage, escalation, remediation
- Authorisation, scope, evidence, reporting

## Security relevance

Understanding the purpose and boundaries of offensive and defensive work helps practitioners choose appropriate methods and handle evidence responsibly.

## Key takeaways

- Offensive security finds weaknesses under authorisation.
- Defensive security monitors and protects systems.
- Effective investigations rely on evidence, context, and clear communication.
- Ethical boundaries and agreed scope are essential.
